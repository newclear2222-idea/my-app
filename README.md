# my-app

미국 주식 적정가 분석 웹사이트 (HTML/CSS/JavaScript만 사용, 서버 불필요)

## 실행 방법

`index.html` 파일을 브라우저로 열면 바로 동작합니다. (탐색기에서 더블클릭)

## 데이터 자동 불러오기 (선택)

1. 무료 API 키를 발급받습니다. FMP와 Finnhub 중 하나만 있어도 되고, 모두 넣으면 가장 많이 채워집니다.
   - [Financial Modeling Prep (FMP)](https://site.financialmodelingprep.com/developer/docs)
   - [Finnhub](https://finnhub.io/register)
   - [Alpha Vantage](https://www.alphavantage.co/support/#api-key) (선택: 선행 PER용 내년 예상 EPS 보완)
2. 사이트의 **API 키 설정**에서 각 키를 붙여넣고 **저장**을 누릅니다.
   키는 이 브라우저의 localStorage에만 저장되며 코드나 GitHub에는 들어가지 않습니다.
3. 티커(예: AAPL)를 입력하고 **불러오기**를 누르면(또는 Enter) 입력칸이 채워집니다.
   자동으로 채운 칸은 파란 테두리와 [FMP] / [Finnhub] 출처 표시가 붙으며, 직접 수정할 수 있습니다.

불러오기 순서: **FMP 먼저 시도 → 막히거나 비어 있는 항목은 Finnhub로 채우기**

| 입력칸 | FMP | Finnhub (보완) |
| --- | --- | --- |
| 현재 주가 | `quote` | `quote` |
| EPS, BPS, 주당 FCF | `ratios-ttm` (최근 12개월) | `stock/metric` (EPS TTM, 분기 BPS, 주당 FCF TTM) |
| 예상 성장률 | `analyst-estimates` 연간 EPS 추정치로 계산한 최대 5년 연평균 성장률 | - |
| 업종 평균 PER | - | `stock/peers`로 경쟁사(최대 10곳)를 찾고, 각 회사의 PER(TTM) 중간값 |

- 업종 PER은 적자(0 이하)와 200배 이상인 회사를 빼고 중간값을 씁니다. 남은 회사가 3곳 미만이면 비워 두고 "직접 입력 필요"로 안내합니다.
  어떤 회사로 계산했는지는 업종 PER 칸 아래와 PER 결과 카드에 표시됩니다.
- 새 티커를 불러오면 이전 종목의 주가·EPS·BPS·FCF·성장률·업종 PER 칸을 먼저 비웁니다.
- 한 번 불러올 때 FMP는 3회, Finnhub는 최대 약 13회 호출합니다.
  Finnhub 무료 플랜(분당 60회)을 넘지 않도록 분당 55회까지만 보내고, 넘을 것 같으면 자동으로 기다립니다.
  같은 회사의 재무 데이터는 10분 동안 다시 부르지 않습니다.
- 어느 쪽에서도 못 가져온 항목은 안내 메시지를 보여주므로 직접 입력하면 됩니다.

### PER 비교 (현재 PER · 업종 PER)

- 현재 PER = 현재 주가 ÷ EPS(최근 12개월). EPS가 0 이하면 "적자로 PER 계산 불가".
- 업종(경쟁사) PER과 비교해 "업종보다 ○% 낮음/높음"을 표시합니다.

### 선행 PER 비교 (애널리스트 기준 · 현재 주가 기준)

- 애널리스트 기준 선행 PER = 애널리스트 목표주가 ÷ 내년 예상 EPS
- 현재 주가 기준 선행 PER = 현재 주가 ÷ 내년 예상 EPS
- 비교 문구 예: `애널리스트는 선행 PER 6.2배를 적정하다고 봄 / 현재 5.0배에 거래 중 → 목표가까지 +25.2%`
- **내년 예상 EPS**: FMP `analyst-estimates` → 없으면 Alpha Vantage `EARNINGS_ESTIMATES`
  - 회계연도 추정치 중 결산일이 지금부터 12개월 뒤에 가장 가까운 것을 씁니다.
    (예: 10월에 12월 결산 회사를 보면, 두 달 남은 올해가 아니라 내년 회계연도)
- **목표주가**: Alpha Vantage `OVERVIEW`의 `AnalystTargetPrice` → FMP `price-target-consensus` → Finnhub `stock/price-target`
  - 애널리스트 수는 Alpha Vantage 투자의견(강력매수~강력매도) 수의 합입니다.
- 두 값 모두 칸에서 직접 고칠 수 있고, 출처·애널리스트 수·기준 회계연도가 칸 아래와 비교 영역에 표시됩니다.
  못 가져오면 "직접 입력 필요"로 안내합니다.
- Alpha Vantage 무료 플랜은 하루 25회입니다. 한 번 불러올 때 1~2회 쓰며, 같은 종목은 1시간 동안 다시 부르지 않습니다.
- 주가·EPS·업종 PER·예상 EPS·목표주가를 직접 고치면 바로 다시 계산됩니다.

## 실적발표 자료 분석 (무료, 규칙 기반)

실적발표 보도자료나 분석 글을 **실적발표 자료 분석** 칸에 붙여넣고 **분석하기**를 누르면 숫자를 찾아 줍니다.
글은 브라우저 안에서만 처리되고 어디에도 저장·전송되지 않습니다.

- 인식 항목: 매출, 매출총이익(률), 영업이익률, 순이익, EPS, 잉여현금흐름(FCF)·주당 FCF·FCF 마진, 영업현금흐름, 설비투자, 주식 수
- 한국어("잉여현금흐름 21억 달러", "전년 대비 +37%", "104~110억 달러")와 영어("free cash flow of $2.1 billion", "$10.4 to $11.0 billion", "plus or minus $0.10")를 지원합니다.
- 분기 실적 / 연간 실적 / 가이던스(분기·연간)를 구분합니다. 기간이 안 적힌 문장은 앞 문장의 기간을 이어받습니다.
- 영업현금흐름과 설비투자만 있으면 FCF = 영업현금흐름 − 설비투자로 계산합니다.
- 각 항목의 **적용** 버튼으로 입력칸에 넣습니다(자동으로 덮어쓰지 않음). 적용한 칸에는 `[실적발표]`가 붙습니다.
  - 회사 전체 FCF → 주식 수로 나눠 주당 FCF (분기 값은 ×4 연환산)
  - 분기 EPS → ×4 해서 EPS(TTM) (대략치), 연간 EPS 가이던스 → 내년 예상 EPS
  - 전년 대비 성장률 → 예상 성장률
- 주식 수는 불러오기 때 FMP(또는 Finnhub) 시가총액 ÷ 주가로 자동 입력되며, 직접 고칠 수 있습니다.
- **추가 정보**: FCF 마진, 연환산 FCF·주당 FCF, FCF 수익률·P/FCF, 다음 분기 매출 가이던스 vs 이번 분기, 연간 EPS 가이던스 vs 내년 예상 EPS, 현재 입력값과의 차이
- 정해진 표현을 찾는 방식이라 표현이 많이 다르면 놓칠 수 있습니다. 항목마다 원문 문장이 함께 보이니 확인 후 적용하세요.

## 계산 방법

| 방법 | 공식 |
| --- | --- |
| PER 기준 | EPS × 업종 평균 PER |
| DCF | 주당 FCF를 5년간 예상 성장률로 늘려 할인율로 할인 + 터미널 가치(영구성장률) |
| 그레이엄 공식 | EPS × (8.5 + 2 × 성장률) |
| PEG | PER(현재가 ÷ EPS) ÷ 성장률, 1 미만이면 저평가 신호 |

- 평균 적정가: PER·DCF·그레이엄 중 계산 가능한 값의 단순 평균 (PEG는 비율이라 제외)
- 괴리율 = (적정가 − 현재가) ÷ 현재가
- 판정: +10% 이상 저평가, −10% 이하 고평가, 그 사이 적정

> 투자 판단 참고용이며 투자 권유가 아닙니다.
