API 키 설정

무료 API 키를 발급받아 입력하세요. 키는 이 브라우저(localStorage)에만 저장되며 어디에도 업로드되지 않습니다. 불러오기는 FMP를 먼저 시도하고, 막히거나 비어 있는 항목은 Finnhub로 채웁니다. FMP와 Finnhub 중 하나만 있어도 됩니다. Alpha Vantage는 선행 PER에 쓰는 내년 예상 EPS를 보완합니다(선택).
