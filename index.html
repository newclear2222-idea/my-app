미국 주식 적정가 분석

4가지 방법으로 적정 주가를 계산하고 현재가와 비교합니다. (단위: $)

API 키 설정

무료 API 키를 발급받아 입력하세요. 키는 이 브라우저(localStorage)에만 저장되며 어디에도 업로드되지 않습니다. 불러오기는 FMP를 먼저 시도하고, 막히거나 비어 있는 항목은 Finnhub로 채웁니다. FMP와 Finnhub 중 하나만 있어도 됩니다. Alpha Vantage는 선행 PER에 쓰는 내년 예상 EPS를 보완합니다(선택).

FMP 주가·EPS·BPS·FCF·성장률

Finnhub 주가·EPS·BPS·FCF (FMP 보완), 경쟁사 기준 업종 PER

Alpha Vantage 애널리스트 컨센서스 내년 예상 EPS (FMP 보완, 무료 하루 25회)

입력

테두리가 파란 칸은 자동으로 채운 값이고, 옆의 [FMP] / [Finnhub]는 출처입니다. 직접 수정할 수 있습니다.

실적발표 자료 분석 무료 · 규칙 기반

실적발표 보도자료나 분석 글을 붙여넣으면 FCF·매출·EPS·성장률·가이던스 숫자를 찾아 줍니다. 원문과 비교해 확인한 뒤 적용을 누르면 입력칸에 들어갑니다. 글은 어디에도 저장·전송되지 않습니다.

관련 기사 Finnhub · 무료

티커를 불러오면 최근 기사가 함께 나옵니다. 기사는 대부분 영어이며, 제목을 누르면 원문 사이트가 새 창으로 열립니다. 실적 관련 기사는 요약을 바로 실적발표 자료 분석으로 보낼 수 있습니다.
